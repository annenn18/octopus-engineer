📏 Before you upload: file limits & tips

File typesWord (.docx), PDF, Excel (.xlsx), text (.txt, .md)
Maximum size50 MB per file
Maximum pages300 pages per PDF — for longer files only the first 300 pages are used
Questions per fileUp to 80 (up to 120 for long documents)
Can't be readScanned PDFs (pictures of pages, no selectable text) · password-protected PDFs · old .doc / .xls files (save them as .docx / .xlsx first)
✓ Works best: study notes, summaries, glossaries and short reports — ideally 1–30 pages — with full sentences, definitions (“Term: explanation”), lists, names, dates and numbers. Bold key terms in Word help.
⚠ Works poorly: whole books, novels, slides with short fragments, or tables of numbers. Questions will feel random. Split long books into chapters, or use the AI chat option for one chapter at a time.

How to format your file

The app recognises any of these. Lines it can't split are skipped and listed so you can fix them.

Separator on each line (any file type, including PDF)
de fiets - the bicycle
het huis = the house
morgen : tomorrow
lekker ; tasty ; Dat is lekker!
A table in Word or Excel
| Dutch     | English   |
| de fiets  | bicycle   |
| het huis  | house     |
Same for an Excel sheet or a table in a PDF. Column 1 = front, column 2 = back, optional column 3 = example sentence. A header row is skipped automatically.
